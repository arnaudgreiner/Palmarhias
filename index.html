Mode d’emploi

Comprendre les multiplicateurs

1 = valeur de référence. 0,5 = moitié ; 2 = double. Attention : augmenter la vitesse d’épuisement ou un délai n’a pas le même effet qu’augmenter la production.

Modifier son monde

Menu principal → Start Game → sélectionner le monde → Change World Settings → Custom Settings. Certains choix sont verrouillés dès la création.

Lire les valeurs

? : valeur ou limite non confirmée. * : défaut rapporté, susceptible de varier selon la version ou le préréglage. Les traductions ne sont pas officielles.

↑ Augmenter · ↓ Diminuer · Off = désactivé · On = activé · PV = points de vie. Défauts indicatifs du mode normal. Sources : Palworld Wiki · Palworld Database. Références de versions différentes ; présence de certaines options à confirmer dans le menu installé.
